プライバシーポリシー

FlashAI · 最終更新日：2026年11月22日

このページは英語版の翻訳です。内容に相違がある場合は、英語版が優先されます。

本ポリシーは、お客様がアプリを利用する際に、FlashAI が情報を収集、利用、保護する方法を説明するものです。本ポリシーを読んだことは、OpenAI へのデータ送信を許可したことを意味しません。AI 機能を利用するには、お客様の別途の同意が必要です。

1. 運営者

本ポリシーは、ベトナムで Truong Huy が運営する FlashAI アプリに適用されます。

2. 収集する情報

アカウントの作成時またはログイン時に、FlashAI は認証とアカウントの表示に必要なプロフィール情報のみを利用します。

  • プロフィール写真（アバター）。
  • アカウント名または表示名。
  • メールアドレス。
  • データの同期と保護に使用するアカウント ID。

3. 第三者サービスによるログイン

Supabase Auth を通じて、Apple、Google、Facebook またはメールアドレスでログインできます。ログイン事業者は、各社のポリシーに従って認証情報を取り扱います。FlashAI は、アカウントの作成、維持、表示に必要なプロフィール情報を受け取ります。

4. アプリ内でお客様が作成するデータ

FlashAI は、お客様が利用する機能を提供するために、デッキ、フラッシュカード、画像、音声、学習の進捗、復習スケジュール、連続学習日数、リマインダーの設定を保存します。フィードバックを送信した場合は、対応のため、その内容とお名前、メールアドレスを保存することがあります。

学習リマインダーを有効にすると、FlashAI はリマインダーを送信するため、アカウントとプラットフォームに紐づいた端末の通知トークンを保存します。リマインダーを無効にするかログアウトすると、その端末のトークンは通知に使用されなくなります。お客様が選択したアプリの言語もプロフィールに保存され、リマインダーやその他のサーバーからのメッセージをその言語で送るために使われます。

FlashAI は、お客様が「AI の許可」ダイアログで別途同意した場合に限り、OpenAI にデータを送信します。カメラや写真ライブラリへのアクセス許可、および本ポリシーを読んだことは、OpenAI へのデータ送信への同意に代わるものではありません。

4a. AI 機能のための OpenAI とのデータ共有

FlashAI は、AI 機能の提供に OpenAI を、発音の採点に Microsoft Azure AI Speech を利用しています。データは Supabase 上の FlashAI のサーバーを経由してこれらの事業者に送信され、処理されます。

  • 画像解析機能で選択、撮影、共有した画像（画像内の文字や情報を含む）。内容を認識してフラッシュカードを作成するために使用します。
  • AI と一緒に使用するテキスト、単語、トピック、フラッシュカードの内容、ファイルから取り込んだ内容。フラッシュカードの作成や補完に使用します。
  • イラストやカバー画像の作成に使用する説明文、単語、例文、デッキのトピック。
  • AI 音声で読み上げるテキスト。
  • 発音モードでは、単語を読み上げるお客様の声の短い録音（最長 6 秒）とその単語が、発音の採点のために Microsoft Azure AI Speech に送信されます。FlashAI は録音を保存せず、マイクは録音ボタンを押したときにのみ使用します。

4b. AI の許可の選択と取り消し

コンテンツには個人情報が含まれる場合があります。使用する権利のあるコンテンツのみを送信してください。同意しない場合でも、学習を続けたり、フラッシュカードを手動で作成したりできます。

この選択は、このアカウントと端末の AI 機能に適用されます。「プロフィール → AI の許可」から取り消すことができます。取り消すと新しい AI リクエストは停止されます。すでに送信されたデータはプライバシーポリシーに従って取り扱われます。

同意しない場合、FlashAI は OpenAI に新しいリクエストを送信せず、ブロックされたリクエストについて AI Credits を確保したり差し引いたりしません。保存済みのコンテンツで学習したり、フラッシュカードを手動で作成したりすることは引き続き可能です。アプリの再インストール、別のアカウントへのログイン、共有範囲の変更を行った場合は、改めて同意をお願いすることがあります。

FlashAI は、OpenAI に送信するリクエストにお客様の名前、メールアドレス、パスワード、ログイントークンを添付しません。ただし、お客様が提供する画像、テキスト、コンテンツに個人情報が含まれる場合があるため、AI を使用する前に内容をご確認ください。

4c. 紹介コード、パートナーリンク、報酬の支払い

FlashAI パートナーの紹介リンク（flashai.academy/r/… など）を開くと、FlashAI はアクセスを記録します。記録するのは、紹介コード、端末の種類（iOS、Android、パソコン）、国、そして訪問者数を数えるために IP アドレスとブラウザから当日分として生成する一方向ハッシュです。FlashAI は IP アドレスを保存しません。

紹介コードを入力した場合、または紹介リンクから Google Play でアプリをインストールした場合、FlashAI はそのコードをお客様のアカウントに紐づけ、AI Credits の付与と、お客様が有料プランを購入した際のパートナーへの報酬の計算に使用します。パートナーが確認できるのは集計データと匿名の顧客 ID のみです。FlashAI がお客様の名前、メールアドレス、学習内容をパートナーと共有することはありません。

すべてのアカウントは紹介パートナーでもあります。招待画面を初めて開くと、FlashAI がお客様専用の紹介コードを作成し、上記のとおり訪問を記録する flashai.academy/r/… のリンクが発行されます。コードを入力した人数、訪問数、売上、報酬、支払い履歴は、ウェブのパートナーページで確認できます。報酬を受け取る場合は、パートナーページで PayPal のメールアドレスを入力します。FlashAI はこのメールアドレスを PayPal で報酬を送る目的にのみ使用し、支払い履歴とともに保管します。アカウントを削除すると、パートナープロフィールの名前、メールアドレス、PayPal のメールアドレスは削除され、すでに発生した報酬および支払いの記録は照合のため保管されます。

4d. アカウント作成前の発音お試し

アプリを初めてインストールしたときのお試しで、同意いただいた場合、お客様が単語を読み上げる短い録音（最長 6 秒）とその単語が、FlashAI のサーバーを経由して採点のために Microsoft Azure AI Speech に送信されます。FlashAI は録音を保存しません。採点回数を制限するため、サーバーはアプリのインストールごとのランダムな ID と、IP アドレスのソルト付きハッシュ（FlashAI は IP アドレスを保存しません）を約 3 日間保存します。

5. 情報の利用目的

  • 認証、ログイン、アカウントの保護。
  • アプリ内でのプロフィール情報の表示。
  • 利用する機能に応じた学習データの保存と同期。
  • お客様がリクエストしたときの AI 機能の提供。
  • 無料プランまたは有料プランの利用権の管理。
  • FlashAI の運営、セキュリティの確保、改善。
  • 通知を有効にした場合の学習リマインダーの送信。
  • 機能の基本的な利用状況の測定とフィードバックへの対応。
  • 紹介コードの記録、AI Credits の付与、報酬の計算と PayPal での紹介パートナーへの支払い。

6. 保存および処理に利用するサービス

FlashAI は、認証とデータ保存に Supabase、AI 機能に OpenAI、発音の採点に Microsoft Azure AI Speech、ソーシャルログインに Apple、Google または Facebook、購入とプランの利用権の管理に RevenueCat と App Store または Google Play、紹介パートナーへの報酬の支払いに PayPal、紹介リンクとパートナーのウェブページの運用に Cloudflare を利用しています。これらの事業者は、各社のポリシーに従ってデータを処理します。

データの受領者は、セキュリティ、利用目的の制限、アクセス管理を含め、本ポリシーにおける FlashAI の約束と同等の水準でデータを保護しなければなりません。当方は OpenAI の API サービスを同社のデータ処理条件に基づいて利用しており、ユーザーデータを広告に使用することを認めていません。

FlashAI がお客様の個人情報を第三者に販売することはありません。

7. 保存期間とセキュリティ

当方は、アプリで可能な範囲で適切な措置を講じ、情報を不正なアクセス、改ざん、開示から保護します。完全に安全なデータの送信方法や保存方法は存在しないため、お客様ご自身でもログイン情報と端末を保護してください。

AI 用のデータは HTTPS で送信されます。OpenAI の API ポリシーでは、不正利用の監視ログにリクエストの内容が含まれることがあり、既定では最長 30 日間、法律や安全上の理由で必要な場合はそれ以上保存されます。実際の保存期間は、データの種類、サービス、OpenAI のポリシーによって異なります。許可の取り消しや FlashAI アカウントの削除によって、OpenAI がすでに受け取ったデータが直ちに削除されるわけではありません。詳しくは https://developers.openai.com/api/docs/guides/your-data および https://openai.com/policies/privacy-policy/ をご覧ください。

情報は、サービスの提供、アカウントの維持、法的義務の履行に必要な期間保存されます。アカウントを削除すると、プロフィールデータ、デッキ、フラッシュカード、学習の進捗、個人ファイルは削除されます。ただし、決済事業者が自社の義務に基づき一部の取引記録を保持する場合があります。

8. お客様の権利と請求

アプリ内の「プロフィール → アカウントを削除」から、アカウントの確認と削除ができます。アカウントの削除は取り消せず、アカウントに紐づく個人データと学習データが削除されます。Sign in with Apple を利用しているアカウントの場合、削除時にアプリが改めて本人確認を行い、Sign in with Apple のアクセス権を取り消します。

FlashAI アカウントを削除しても、App Store または Google Play で購入したサブスクリプションは解約されません。自動更新を避けるため、ストアのサブスクリプション設定で別途解約してください。データに関するご請求は hello.truonghuy@gmail.com までご連絡いただくこともできます。

9. 本ポリシーの変更

機能、サービス、関連する規制が変更された場合、本プライバシーポリシーを更新することがあります。新しい版は、冒頭の更新日とともにこのページに掲載されます。
